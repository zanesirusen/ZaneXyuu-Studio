# ZaneXyuu Studio

Website modern dan responsive dengan navigasi:
- Home
- Free Asset
- Product
- Discord

## Teknologi
- Vite
- React
- TypeScript
- Tailwind CSS

## Menjalankan secara lokal

1. Buka terminal di folder proyek ini.
2. Jalankan:

```bash
npm install
npm run dev
```

3. Buka `http://localhost:4173`.

## Deploy ke Vercel melalui GitHub

1. Buat repository baru di GitHub dan push seluruh folder proyek.
2. Masuk ke dashboard Vercel.
3. Pilih "Import Project" dan sambungkan ke repository GitHub.
4. Gunakan pengaturan default. Vercel akan mendeteksi proyek Vite dan menjalankan build otomatis.

Selesai! Website ini sudah siap di-hosting di Vercel.
